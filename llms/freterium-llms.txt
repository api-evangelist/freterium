# Freterium

> Freterium is a cloud-native AI Transport Management System (TMS) — a unified operating system for supply chain and logistics that connects shippers, carriers, and fleets on a single intelligent layer. It spans first-mile, middle-mile, and last-mile operations across eight integrated modules and offers a documented REST API for ERP/WMS integration.

Generated by the API Evangelist enrichment pipeline from the public Freterium website. The website redirected from freterium.com to freterium.ai (rebrand). No public OpenAPI/Swagger specification was discoverable at time of generation; the REST API is documented for customers and integration partners.

## Product

- [Platform overview](https://freterium.ai/platform): Order Management, Smart Planning (AI route optimization), Collaborative Portals, Real-time Tracking, Fleet Management, Billing & Costing, Intelligent Doc Control, Analytics & Reporting.
